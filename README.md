# Electric Vehicle Market Performance & Insights

## Project Overview
This project uses Tableau to explore electric vehicle (EV) market data and identify patterns across manufacturers, countries, battery capacity, DC charging power, and annual sales.

## Objectives
- Compare vehicle counts by manufacturer.
- Analyze vehicle distribution by manufacturing country.
- Compare average DC charging power by manufacturer.
- Compare average battery capacity by manufacturer.
- Explore annual EV sales trends by model year.

## Tools Used
- Tableau
- CSV dataset

## Dashboard
The interactive Tableau dashboard is available through the Demo Link submitted with this project.

## Key Note
This dashboard presents exploratory analysis of the provided dataset. Findings should be interpreted in the context of the dataset's coverage and definitions.
